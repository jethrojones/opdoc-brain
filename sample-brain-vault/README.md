# Sample Brain Vault

A fully fictional Obsidian vault for demonstrating how an AI can read, connect, and write durable context.

Everything in this folder is invented. It contains no real people, credentials, customers, or private work.

## Open it in Obsidian

1. Download or copy this `sample-brain-vault` folder.
   The standalone public copy is at [github.com/jethrojones/sample-brain-vault](https://github.com/jethrojones/sample-brain-vault).
2. In Obsidian, choose **Open folder as vault**.
3. Open [[VAULT-INDEX]] first, then follow the links to projects, people, daily notes, and tasks.

## What to demonstrate

- The index is short and routes an AI to deeper notes.
- [[Projects/Riverside Workshop Series]] connects people, decisions, files, and next actions.
- [[01 - Daily Notes/2026-08-12]] shows the record of work, while [[00 - Inbox/Agent Tasks]] holds work still open.
- [[Resources/Workshop Registration Snapshot]] shows how reference material can be retained without crowding the index.
- `AGENTS.md` shows the read-first instruction an AI uses when it works with the vault.

`AGENTS.md` is illustrative here. The AI Memory Vault Builder writes a person’s actual confirmed local vault path into their own generated version.

## Safe demo prompts

```text
Read VAULT-INDEX.md first. What is Riverside Workshop Series trying to accomplish this month? Name the source files you used.
```

```text
Read the relevant notes for Riverside Workshop Series. What decisions have been made, what remains open, and what is the next useful action? Name the files you used. Do not change anything.
```

```text
Read the vault first. Summarize tomorrow's to-do list and name the daily-note file where it lives.
```
