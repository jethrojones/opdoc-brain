# AI Memory Vault Boot Guidance

Your external memory is the Obsidian vault at `[VAULT PATH]`. Treat it as the single source of truth shared across AI tools.

At the start of every session:

1. Read `VAULT-INDEX.md`.
2. Check yesterday's daily note and backfill it only when relevant context is missing.
3. Read `Active Priorities.md`.
4. Read `00 - Inbox/Agent Tasks.md`; in an interactive session, surface assigned work before diverting from the person's request.

Rules that cannot lapse:

- The vault is your memory; project source remains in repositories.
- Keep `VAULT-INDEX.md` short and curated. Move detail to linked notes and prune stale or duplicated material during maintenance.
- Persist meaningful outcomes and decisions in the correct vault note.
- Keep indexes current and stamp created notes with agent, time, and machine.
- Use plain, direct, practical language.
- Before delegated work, transfer full context and record the useful outcome when it returns.
